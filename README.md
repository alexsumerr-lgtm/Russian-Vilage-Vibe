# Уголок мастерской

Интерактивная 3D-диорама для браузера: столярный уголок в дачном сарае, 70-е годы, вечер после дождя.
three.js, запечённый свет, звуки, приёмник, мотоцикл за окном.

Это готовая сборка для просмотра: страница `index.html` и файлы, которые она загружает. Исходники Blender сюда не входят.

## Как открыть локально

Страницу нужно открывать через веб-сервер, а не двойным щелчком по файлу:

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

Потом откройте http://localhost:8000/ в браузере. `--bind 127.0.0.1` оставляет сервер доступным только с этого компьютера.

## Песни приёмника

Аудиофайлы из папки [`radio`](radio/) играет приёмник на верстаке: щёлкните по нему, затем ▶ в строке «Приёмник».
Как добавить песни, написано в [radio/README.md](radio/README.md).
