# Песни для приёмника

Аудиофайлы из этой папки играет приёмник на верстаке. Щёлкните по приёмнику, и он включится с шумом эфира.
Потом нажмите ▶ в строке «Приёмник». Песни идут одна за другой в порядке имён файлов, ◀◀ и ▶▶ переключают их.

- **Форматы:** лучше всего MP3, он играет во всех браузерах. Подойдут M4A/AAC, WAV и FLAC; OGG и Opus играют не везде.
- **Порядок:** задаётся именами файлов, например `01 Первая.mp3`, `02 Вторая.mp3`. Номер в начале имени на экран не выводится.
  Если в файле есть теги, название берётся из них: «Исполнитель — Песня».
- **Размер:** через сайт GitHub можно загрузить файл до 25 МБ, через git до 100 МБ. Обычная песня в MP3 весит 3–10 МБ.

## Как добавить песни

**На GitHub:** откройте эту папку в репозитории → Add file → Upload files → перетащите файлы → Commit changes.
Через одну-две минуты, когда GitHub обновит сайт, песни заиграют. Пересобирать ничего не нужно.

**На компьютере:** положите файлы в папку `radio` рядом с `index.html`. Через локальный сервер они играют сразу.
На сайт они попадут после коммита и отправки на GitHub.

## Важно

- Сайт публичный, и любой посетитель может скачать эти файлы. Кладите сюда только то, что можно распространять:
  свои записи или музыку со свободной лицензией.
- Файлы, купленные в iTunes и некоторых других магазинах, хранят в тегах имя и почту покупателя.
  Перед загрузкой через сайт GitHub такие теги лучше удалить; сборка проекта вырезает их сама.
